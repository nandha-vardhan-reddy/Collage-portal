# Collage-portal
Secure and responsive College Group Portal featuring an authenticated login system and a dynamic dashboard. Designed to streamline communication, manage updates, and enhance collaboration among members through a clean UI and structured layout. Built with a focus on security, usability, and performance.

# 🚀 Features

🔐 Secure Login Authentication

📊 Interactive Dashboard

📱 Fully Responsive Design

🎨 Clean and User-Friendly Interface

⚡ Fast and Lightweight Performance

# 🛠️ Technologies Used

HTML5 – Structure of the web pages

CSS3 – Styling and responsive design

JavaScript – Interactivity and dynamic functionality

# 📂 Project Structure
/project-folder
│── index.html
│── dashboard.html
│── style.css
│── script.js

⚙️ How to Run

Download or clone the repository

Open index.html in your browser

Login to access the dashboard

🎯 Purpose

This project was developed to demonstrate front-end development skills, including UI design, authentication handling, and dashboard creation using core web technologies.
